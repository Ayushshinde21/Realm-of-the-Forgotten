Uncial Antiqua
===============

The HUD is configured to use Uncial Antiqua.

Official Google Fonts source:
https://fonts.google.com/specimen/Uncial+Antiqua

The font is licensed under the SIL Open Font License (OFL) 1.1.
If UncialAntiqua-Regular.ttf is not bundled in this project, install the font on Windows and the game will detect it automatically.
